## The build of record

Lean builds and the Lean-dependent audit gates run on the UConn Storrs HPC cluster (Slurm; CLAUDE.md Rule 26).
`scripts/hpc-package.py` packages a clean commit and refuses moved pins; the job (`scripts/hpc-leanbuild.sh`)
builds from empty and runs the seven gates of `scripts/Audit-Round.ps1`, the round axiom scan, the hypothesis census,
the map-identifier scan and the `leanchecker` kernel replay; `scripts/hpc-verify-return.py` re-derives every verdict
from the returned logs and compares the returned source with the local tree file by file. `REPRODUCIBILITY.md` has the
commands, including the local route for a targeted check.
